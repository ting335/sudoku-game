# 静心一局 · 数独与扫雷

软件工程课程项目，对应任务书 **“数独游戏（或其他类别游戏）”**。为大道公司设计一款可在一个月内开发并上线的轻量益智网页游戏，以数独为核心，扫雷作为同一入口下的扩展玩法。使用原生 HTML、CSS、JavaScript 和 Web Audio，无需安装前端依赖。

- **直接玩游戏：[打开在线试玩](https://ting335.github.io/sudoku-game/)**（GitHub Pages）
- **查看代码：[打开 GitHub 仓库](https://github.com/ting335/sudoku-game)**

上方两个地址用途不同：试玩地址进入游戏，仓库地址查看代码。仓库名称仍为 `sudoku-game`，增加扫雷后无需更换网址。**2026-11-01 已实际检查试玩地址返回 HTTP 200，公开页面包含双游戏入口和手机插旗控件。** 无需项目邀请码、注册或安装即可试玩。若更新后看到旧页面，请在 Pages 部署完成后按 Ctrl+F5 刷新。

## 目标用户与使用场景

以下是根据小游戏任务规模拟定的产品定位，尚未进行代表性用户访谈或问卷统计。

| 目标用户 | 场景与需求 | 设计应对 |
|---|---|---|
| 课间或工作间隙的休闲玩家 | 有一段短暂空闲，希望少操作就能开始，随时中断 | 免登录网页、难度选择、暂停、本机存档、可关闭声音 |
| 数独或扫雷初学者 | 不熟悉规则，容易因误操作放弃 | 游戏说明、数独三级提示与错误反馈、扫雷首击安全、触屏插旗开关 |
| 已掌握基础规则的玩家 | 希望有更高难度或新规则 | 数独三档难度、对角线/偶数及组合规则，扫雷三档规格与最佳用时 |

典型路径：新玩家从试玩链接进入 → 查看规则 → 选择游戏和难度 → 操作棋盘并获得反馈 → 暂停或继续 → 完成/失败后查看结果并重新开局。返回同一浏览器时可恢复未完成局面；跨设备接续不在首版范围。

## 竞品分析与范围取舍

资料查看日期：2026-11-01。下表依据产品官网公开页面，属于功能观察；没有使用竞品的代码、素材或用户数据，也没有进行完整性能对比。

| 参考产品 | 官网可见能力 | 对本项目的启发与取舍 |

本项目定位为两种经典益智游戏的轻量入口，重点在操作清晰、舒缓反馈和随时暂停。选择该范围是为了在一个月内控制开发与运维成本，不意味着其功能全面程度超过成熟竞品。

首版范围外：多人联机、账户、云同步、在线排行榜、付费与广告系统、App/小程序安装包、冷启动离线缓存。按钮“今日挑战”仍为随机开局，不宣称已提供每日固定题。手动笔记已支持添加/取消候选、擦除、撤销/重做和保存恢复；候选仅作记录，不自动保证正确。

## 技术选择与运行架构

```text
普通用户浏览器 ── HTTPS ── GitHub Pages（HTML/CSS/JS/SVG 静态文件）
       │
       ├─ 数独界面与生成/校验、提示模块
       ├─ 扫雷界面与棋盘/计时/胜负模块
       ├─ 共用主题、Web Audio 声音
       └─ localStorage：当前浏览器进度、纪录、声音偏好
```

| 选择 | 原因及代价 |
|---|---|
| 网页而非原生 App / 小程序 | 一个链接即可试玩，适合课堂演示与分享；不依赖应用商店审核。浏览器声音、存储与兼容性需要专门处理 |
| 原生 JavaScript + ES 模块 | 游戏规模小，无需构建工具和依赖安装，便于团队理解与答辩；模块边界和状态同步由项目自行维护 |
| GitHub Pages 静态托管 | 无服务器部署，推送后可发布；不提供本项目所需的账户或数据库后端，因此不做可信在线排名 |
| localStorage + Web Audio | 局面和声音在本机处理，音频无需下载；清除站点数据会丢存档，声音必须由用户操作解锁 |

页面和源码由托管服务通过网络提供；棋盘计算与进度保存由浏览器执行。本项目没有自建用户数据后端，未接入统计、支付或广告 SDK。性能和兼容性以实际测试为准，不给出未经测量的并发、首屏耗时或设备全覆盖承诺。

## 本地运行

需要 Python 3；自动测试另需 Node.js 20 或以上版本。在项目目录运行：

```powershell
python scripts/serve.py
```

打开 <http://127.0.0.1:8000/>。服务器仅监听本机；按 Ctrl+C 停止。通过 HTTP 打开页面以加载 ES 模块，直接双击 HTML 不属于支持的运行方式。

如果 8000 端口被其他程序占用，可运行 `python scripts/serve.py 8001`，然后打开 <http://127.0.0.1:8001/>。`127.0.0.1` 仅用于在运行服务器的电脑上预览，分享给其他人请使用上方在线试玩链接。

## 双游戏切换与扫雷

顶部点击“数独”或“扫雷”切换，双方游戏进度独立保存在当前浏览器；切到另一游戏或后台时停止原游戏计时。两者共用一份音乐、音效和音量设置，避免重复播放。

| 扫雷难度 | 棋盘（列 × 行） | 地雷数 |
|---|---|---|
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 30 × 16 | 99 |

- 揭开所有非雷格获胜；数字表示周围八格的雷数。首次揭开格及周围八格不布雷，之后仍可能需要猜测。
- 左键揭开，右键按“旗帜 → 问号 → 空格”循环标记。手机开启“插旗模式”后点格子标记，再关闭开关继续揭开。
- 已打开的数字周围旗数与数字相符时，点击数字或按空格展开邻格；旗帜标错仍可能踩雷。
- 键盘方向键移动、空格揭开、F 标旗。暂停会禁止鼠标和键盘修改局面。
- 新游戏、重开、笑脸按钮均生成一局新棋盘，不重放原雷位；切换进行中的难度需要确认。
- 最佳记录按难度分别保存。损坏或不符合当前棋盘规格的存档会忽略并新开一局。
- 高级棋盘在窄屏中允许棋盘容器横向滚动，页面本身保持正常宽度；保留队友的复古扫雷格子，补充了暗色主题配色、误标旗显示和独立帮助。

扫雷桌面布局与数独保持一致：**左栏为难度设置、分档纪录和规则，中间为棋盘、计时及插旗/暂停，右栏为声音、新局与快捷键**。初级棋盘格子随视口放大；中高级保持可辨识的格子尺寸，宽度超出时仅在棋盘容器内滚动。高级显示横向滚动提示。手机端棋盘优先，两个设置侧栏排在棋盘下方，全部功能继续可用。

右侧“棋盘图标说明”和完整玩法教学都附有与棋盘相同样式的图例：**🚩 旗帜**表示玩家怀疑有雷；**浅红底 ×**表示结算时确认插错旗，该格没有雷；**红底 ◈**表示结算时显示的、未插旗的地雷；**亮红底 💥**表示这次踩中的地雷，导致失败。正确标在雷上的旗在结算后保留旗帜。完整教学还解释问号、邻域数字与空白；表情符号的具体外形可能随设备变化，含义以文字说明为准。

## 玩法与模式

| 模式 | 规则 | 操作 |
|---|---|---|
| 经典数独 | 每行、每列、每个 3×3 宫包含 1–9，不能重复 | 关闭两个附加规则按钮 |
| 对角线数独 | 在经典规则上，两条主对角线也不能有重复数字 | 点击棋盘上方“对角线” |
| 偶数数独（新增） | 圆圈标记格只能填 2、4、6、8；未标记格仍可填任意合法数字 | 点击“◯ 偶数” |
| 对角线＋偶数 | 同时满足上述两类附加规则 | 同时开启两个按钮 |

开启偶数/对角线规则后，说明统一显示在左侧“数独规则”卡片内。对角线按钮使用固定的 × 图标，以底色、边框和按下状态区分开关，不旋转成加号。

模式或难度切换需要确认并开始新局。偶数标记从当前答案中生成，优先选取 12 个原本为空的偶数格；空格不足时使用实际可选数量。标记随存档一起保留。候选数、高亮提示和填数检查会感知当前规则。

初级侧重单候选，中级侧重隐性唯一位置，高级可能需要进一步推理；这些是生成目标，生成器设有重试和保留唯一解的兜底，并非经过人类技巧难度认证。难度旁“？”可查看说明。

## 操作与反馈

### 第一次玩：新手教学

右上角的 **“? 玩法说明”** 是规则与操作入口，替代原来的单独问号。每次打开页面，数独首次进入会自动展示教学；本次访问第一次切到扫雷时也会展示对应说明。勾选 **“下次进入数独/扫雷不再自动显示”** 后，会在当前浏览器分别记住选择；仍可随时点击“玩法说明”重新打开，取消勾选即可恢复下次自动显示。存储不可用时本次访问内只自动显示一次，不影响手动打开。

数独教学直接分为“1．游戏规则”和“2．怎么操作”，说明行、列、宫及填数、笔记、提示、擦除和暂停。扫雷教学解释邻域数字、首击安全、手机插旗与快速展开的风险。教学正文为 16px，桌面窗口最大宽度 820px，内容区独立滚动，关闭按钮、“不再显示”和开始按钮始终可达。打开教学会暂停对应游戏计时与音乐，关闭后保持原有手动暂停状态。

数独基础说明采用精简版：“每一宫”图标由真实的 **3 行 × 3 列九格**组成，规则与常用操作直接展示，说明直接分成“1．游戏规则”和“2．怎么操作”，取消展开层级。已在 1280×720 和 1366×768 检查默认内容无需内部滚动；窄屏、放大或展开详情时仍可滚动。

界面同时加大棋盘、数字、规则正文与主要操作文字；手机棋盘上方工具分为两行，避免放大文字后挤出屏幕。小高度窗口允许自然滚动。

- 点选格子，再点数字键或按键盘 1–9 填入；Backspace / Delete 擦除。
- 方向键移动；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 重做。
- 三级提示：显示候选数、高亮唯一位置、直接填入一个确定数字；无确定位置时显示说明。
- “显示候选数”和“唯一位置高亮”现在是独立开关，菜单用明暗与按下状态表示开关，不在名称后追加状态文字；开启后会随当前局面的输入、擦除和撤销重算。关闭只移除对应的自动提示，保留手动笔记和正式答案。自动候选仍沿用仅展示 1–4 个候选的空格规则，不覆盖已有手动笔记。“直接填入”保持一次性操作。刷新页面或开始新局后，两种显示开关默认关闭；自动提示不作为手动笔记存档。
- 正确输入有清亮短音；错误输入有低音、闪红和抖动，相关冲突格联动高亮。
- 支持暂停、明暗主题、计时、进度与当前浏览器存档。
- 夜间题目数字为浅色粗体，自己填写的数字为青色下划线。
- “今日挑战”目前按所选模式随机开局，尚未实现按日期固定同一道题。

### 手动笔记怎么用

点选空格，开启 **“✎ 笔记”** 后，点数字记录小号候选。例如可能是 2 或 5，就分别点 2、5；再点同一个数字可取消。关闭笔记后输入正式答案，会替换该格所有笔记。“擦除”清空当前格的答案或笔记；普通笔记编辑支持撤销/重做与刷新恢复，最近 50 次操作可回退。笔记不计入进度，不增加错误次数，不会自动删除其他格子的候选；已有正式答案的格子应先擦除再记笔记。题目数字不能改。按钮开启时显示“笔记：开”，棋盘下方显示操作说明。

## 音乐与音效

在“声音与氛围”点击“播放音乐”；成功后按钮显示“暂停音乐”。音乐和音效有独立开关，音量范围为 0–100%，偏好保存在本机。旋律由 Web Audio 本地合成，无需下载音乐文件。

配乐随游戏切换：**数独为舒缓和弦与稀疏旋律，扫雷为小调琶音与低音脉冲**。切换时保留开关和音量，不会自动打开用户已关闭的音乐；共用一个 AudioContext 和播放循环，替换音乐场景时让旧声音淡出，音效保持独立。

浏览器需要用户交互才能播放。刷新后可点击“点击恢复”或棋盘恢复已启用的音乐；暂停游戏或离开页面时背景音乐停止，数独完成时也停止背景音乐。若按钮显示正在播放仍听不到，请检查标签页静音、系统音量和滑块。音频不支持或播放被拒绝时，仍可继续游戏。

2026-10-31 修复了界面与音频模块的接口不匹配：使用 `setMusicEnabled` / `setEffectsEnabled`，音量直接传入 0–100 数值，避免重复除以 100；旧版误存的 0.35 自动恢复为 35%。

## 页面适配

电脑端采用三栏布局：左侧进度/记录/规则、中间棋盘、右侧声音/新局/快捷键。左右栏等宽，使棋盘位于屏幕中央；减少标题装饰留白，适当放大棋盘与数字。棋盘随视口高度调整，本轮放大后的桌面尺寸上限为 680px；小窗口仍可滚动访问全部控件。难度箭头使用独立定位的 CSS 图标，保持垂直居中。

数独三栏布局此前已在 1366×768、1280×720、320×760、390×844 检查；本次在此基础上保留队友的双游戏入口。窄屏采用单列，信息卡片在棋盘下方自然滚动，不隐藏功能。扫雷初级已在 390px 视口检查无页面横向溢出；大棋盘使用容器内滚动。

提示菜单向上展开；开启减少动态效果的系统选项时减少动画。浏览器放大或高度较小的窗口仍可能需要纵向滚动。
