# 静心一局 · 数独与扫雷

软件工程课程项目。使用原生 HTML、CSS、JavaScript 和 Web Audio，无需安装前端依赖。

- **直接玩游戏：[打开在线试玩](https://ting335.github.io/sudoku-game/)**（GitHub Pages）
- **查看代码：[打开 GitHub 仓库](https://github.com/ting335/sudoku-game)**

上方两个地址用途不同：试玩地址进入游戏，仓库地址查看代码。仓库名称仍为 `sudoku-game`，增加扫雷后无需更换网址。2026-10-31 已实际检查试玩地址返回 HTTP 200。若更新后看到旧页面，请在 Pages 部署完成后按 Ctrl+F5 刷新。

## 本地运行

需要 Python 3；自动测试另需 Node.js 20 或以上版本。在项目目录运行：

```powershell
python scripts/serve.py
```

打开 <http://127.0.0.1:8000/>。服务器仅监听本机；按 Ctrl+C 停止。通过 HTTP 打开页面以加载 ES 模块，直接双击 HTML 不属于支持的运行方式。

如果 8000 端口被其他程序占用，可运行 `python scripts/serve.py 8001`，然后打开 <http://127.0.0.1:8001/>。`127.0.0.1` 仅用于在运行服务器的电脑上预览，分享给其他人请使用上方在线试玩链接。

## 双游戏切换与扫雷

顶部点击“数独”或“扫雷”切换，双方游戏进度独立保存在当前浏览器；切到另一游戏或后台时停止原游戏计时。两者共用一份音乐、音效和音量设置，避免重复播放。

| 扫雷难度 | 棋盘（列 × 行） | 地雷数 |
|---|---|---|
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 高级 | 30 × 16 | 99 |

- 揭开所有非雷格获胜；数字表示周围八格的雷数。首次揭开格及周围八格不布雷，之后仍可能需要猜测。
- 左键揭开，右键按“旗帜 → 问号 → 空格”循环标记。手机开启“插旗模式”后点格子标记，再关闭开关继续揭开。
- 已打开的数字周围旗数与数字相符时，点击数字或按空格展开邻格；旗帜标错仍可能踩雷。
- 键盘方向键移动、空格揭开、F 标旗。暂停会禁止鼠标和键盘修改局面。
- 新游戏、重开、笑脸按钮均生成一局新棋盘，不重放原雷位；切换进行中的难度需要确认。
- 最佳记录按难度分别保存。损坏或不符合当前棋盘规格的存档会忽略并新开一局。
- 高级棋盘在窄屏中允许棋盘容器横向滚动，页面本身保持正常宽度；保留队友的复古扫雷格子，补充了暗色主题配色、误标旗显示和独立帮助。

## 玩法与模式

| 模式 | 规则 | 操作 |
|---|---|---|
| 经典数独 | 每行、每列、每个 3×3 宫包含 1–9，不能重复 | 关闭两个附加规则按钮 |
| 对角线数独 | 在经典规则上，两条主对角线也不能有重复数字 | 点击棋盘上方“对角线” |
| 偶数数独（新增） | 圆圈标记格只能填 2、4、6、8；未标记格仍可填任意合法数字 | 点击“◯ 偶数” |
| 对角线＋偶数 | 同时满足上述两类附加规则 | 同时开启两个按钮 |

模式或难度切换需要确认并开始新局。偶数标记从当前答案中生成，优先选取 12 个原本为空的偶数格；空格不足时使用实际可选数量。标记随存档一起保留。候选数、高亮提示和填数检查会感知当前规则。

初级侧重单候选，中级侧重隐性唯一位置，高级可能需要进一步推理；这些是生成目标，生成器设有重试和保留唯一解的兜底，并非经过人类技巧难度认证。难度旁“？”可查看说明。

## 操作与反馈

- 点选格子，再点数字键或按键盘 1–9 填入；Backspace / Delete 擦除。
- 方向键移动；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 重做。
- 三级提示：显示候选数、高亮唯一位置、直接填入一个确定数字；无确定位置时显示说明。
- 正确输入有清亮短音；错误输入有低音、闪红和抖动，相关冲突格联动高亮。
- 支持暂停、明暗主题、计时、进度与当前浏览器存档。
- 夜间题目数字为浅色粗体，自己填写的数字为青色下划线。
- “今日挑战”目前按所选模式随机开局，尚未实现按日期固定同一道题。

## 音乐与音效

在“声音与氛围”点击“播放音乐”；成功后按钮显示“暂停音乐”。音乐和音效有独立开关，音量范围为 0–100%，偏好保存在本机。旋律由 Web Audio 本地合成，无需下载音乐文件。

浏览器需要用户交互才能播放。刷新后可点击“点击恢复”或棋盘恢复已启用的音乐；暂停游戏或离开页面时背景音乐停止，数独完成时也停止背景音乐。若按钮显示正在播放仍听不到，请检查标签页静音、系统音量和滑块。音频不支持或播放被拒绝时，仍可继续游戏。

2026-10-31 修复了界面与音频模块的接口不匹配：使用 `setMusicEnabled` / `setEffectsEnabled`，音量直接传入 0–100 数值，避免重复除以 100；旧版误存的 0.35 自动恢复为 35%。

## 页面适配

电脑端采用三栏布局：左侧进度/记录/规则、中间棋盘、右侧声音/新局/快捷键。左右栏等宽，使棋盘位于屏幕中央；减少标题装饰留白，适当放大棋盘与数字。1366×768 下棋盘约 437 px（上一版约 377 px），1920×1080 下约 609 px。难度箭头使用独立定位的 CSS 图标，保持垂直居中。

数独三栏布局此前已在 1366×768、1280×720、320×760、390×844 检查；本次在此基础上保留队友的双游戏入口。窄屏采用单列，信息卡片在棋盘下方自然滚动，不隐藏功能。扫雷初级已在 390px 视口检查无页面横向溢出；大棋盘使用容器内滚动。

提示菜单向上展开；开启减少动态效果的系统选项时减少动画。浏览器放大或高度较小的窗口仍可能需要纵向滚动。

## 发布与协作

GitHub 仓库 Settings → Pages：选择 Deploy from a branch、`main`、`/(root)`。推送到 main 后等待 Pages 部署完成；若仍看到旧版，强制刷新。静态资源带版本参数以减少更新时的缓存混用。

每次开发先获取队友最新提交，按实际修改内容提交。当前无账号、云端同步、在线排行榜。局面只存于本机浏览器；清空站点数据或换设备无法恢复。已加载页面可继续解题，断网后全新打开站点的离线缓存尚未实现。

## 代码导航

| 文件 | 职责 |
|---|---|
| `index.html` | 页面、双游戏切换、扫雷布局 |
| `src/main.js` / `src/hint.js` | 当前数独生成、交互、三级提示 |
| `src/core/even.js` | 偶数标记规则 |
| `src/minesweeper.js` | 扫雷棋盘、布雷、胜负、计时和存档 |
| `src/minesUI.js` | 扫雷界面、触屏插旗、键盘和音频控件 |
| `src/audio.js` | 两游戏共用的本地合成声音 |
| `src/styles.css` / `tests/` | 数独主题与响应式布局 / 回归测试 |

当前数独入口使用 `main.js` 中的生成器；`src/core` 另有早期逻辑模块，不能据此认为当前入口已启用 Worker。项目无需后端或 npm 安装，部署只需静态文件。
