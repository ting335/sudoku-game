# 居中棋盘与控件细化

本次仅修改页面结构、样式和 README，未修改玩法或音频逻辑。

- 电脑采用等宽左右栏，中间棋盘：左侧进度/记录/规则，右侧音乐/新局/快捷键；较窄窗口自动恢复单列，并将棋盘放在第一位。
- 将键盘说明移动到右栏，减少主标题留白，给棋盘腾出空间；1366×768 棋盘由约 377 px 增大到约 437 px。
- 修复难度箭头原先固定 top:3px 导致的偏移，使用 50% 定位和 CSS 边框图标；选择框、模式按钮、提示按钮与卡片圆角统一。
- 侧栏文字适度放大；保留夜间题目/手填数字区分、对角线和偶数标记。
